# SIDEFORM

Minimal, understated streetwear. **Made for your own direction.**

## Project status

Initial brand and storefront concept, prepared for the next design and Shopify implementation steps. The current site is a static prototype, not a Shopify theme. Checkout, payments, inventory, and orders are not connected.

## Contents

- `site/` — responsive homepage prototype with product previews and a sample bag.
- `site/assets/` — AI-generated campaign and garment concept imagery.
- `brand/CONCEPT.md` — brand direction and visual identity notes.
- `brand/mark.svg` — editable offset two-bar symbol.

## Preview locally

From this folder, run `python -m http.server 4173 --directory site`, then open http://localhost:4173.

No dependencies or build step are required. The preview bag is temporary and clears on reload.

## Next steps

Agree on the first collection, confirm product specifications and pricing, then implement the approved design as a Shopify theme. Brand name availability has not been cleared.
